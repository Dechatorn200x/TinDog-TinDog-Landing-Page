# TinDog — Landing Page Project

โปรเจกต์เว็บไซต์ Landing Page สำหรับแอปหาเพื่อนให้น้องหมา (**TinDog**) ที่สร้างขึ้นจากการศึกษาและลงมือทำตามวิดีโอด้วยตัวเอง เพื่อฝึกฝนการใช้งาน **HTML**, **CSS** และ **Bootstrap 5**[cite: 1, 2]

## Tech Stack & Concepts Used
- **HTML5**: โครงสร้างหน้าเว็บแบบแบ่ง Section (`#title`, `#features`, `#testimonial`, `#pricing`, `#footer`) รวมถึงการใช้ Inline SVG ไอคอน
- **CSS3 (External CSS)**: ตกแต่งสไตล์เพิ่มเติมใน `css/style.css` เช่น พื้นหลังไล่สีเคลื่อนไหว (`.gradient-background` ร่วมกับ `@keyframes gradient-animation`), รูปโปรไฟล์วงกลม (`.profile-img`) และ Media Query[cite: 2]
- **Bootstrap 5**: จัดเลย์เอาต์แบบ Responsive ด้วย Grid System (`container`, `row`, `col-*`), ปุ่ม (`btn`), การ์ดราคา (`card`) และ Utility Classes (`py-5`, `pt-5`, `g-5`, `text-center` ฯลฯ)[cite: 1, 2]

## Sections Overview
1. **Hero / Title**: พื้นหลังไล่สีเคลื่อนไหว พร้อมหัวข้อหลัก ปุ่มดาวน์โหลด (Apple / Google Play) และภาพตัวอย่างหน้าจอ iPhone[cite: 1, 2]
2. **Features**: จุดเด่น 3 คอลัมน์ (*Easy to use*, *Elite Clientele*, *Guaranteed to work*)
3. **Testimonial**: รีวิวผู้ใช้งานพร้อมรูปภาพและโลโก้สื่อต่างๆ (TechCrunch, Mashable, Business Insider, TNW)[cite: 1, 3, 6, 7, 8]
4. **Pricing**: แพ็กเกจราคา 3 ระดับ (*Chihuahua*, *Labrador*, *Mastiff*)[cite: 1]
5. **Footer**: ส่วนท้ายเว็บพร้อมลิงก์หมวดหมู่ต่างๆ[cite: 1]

โปรเจกต์นี้ทำขึ้นเพื่อฝึกทักษะการเขียนเว็บและการจัดเลย์เอาต์ตามบทเรียนวิดีโอ โดยลงมือเขียนและปรับแต่งโค้ดด้วยตัวเองทั้งหมด[cite: 1, 2]
